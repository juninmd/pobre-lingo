# **App Name**: PobreLingo

## Core Features:

- Rule Categorization: Categorize English grammar rules into understandable and easily searchable topics.
- Rule Explanations: Create clear, concise, and user-friendly explanations for each rule, in Portuguese.
- Example Sentences: Offer diverse example sentences in English that clearly show how the grammar rule works in different contexts.
- Sentence Checker: Incorporate an AI tool to analyze user-submitted sentences and provide feedback, indicating mistakes and offering suggestions for improvement.
- Personalized Quiz Generator: Use AI to generate quizzes and tests customized to the user's current understanding and learning objectives, providing personalized education.
- Rule Tracking: Make it easy to bookmark, tag, or otherwise keep track of specific rules for later review or quick access.
- Sentence Ordering: Interactive exercise where the user must arrange words in the correct order to form a grammatically correct sentence.
- Correct Sentence Identification: Present users with a selection of sentences and have them identify the grammatically correct ones.
- Learning Streak: Track and display a streak of consecutive days the app has been used to encourage consistent learning.
- Share Learning Streak: Add a share button for WhatsApp or Instagram of the lesson streaks I made, with the message: I'm on a cool streak of x days on PobreLingo.

## Style Guidelines:

- Primary color: Soft blue (#64B5F6) for a calm, educational feel.
- Background color: Light gray (#F0F4F7) to ensure comfortable readability.
- Accent color: Yellow (#FFD54F) to highlight important rules and call attention to interactive elements.
- Body and headline font: 'PT Sans' (sans-serif) for a clean, accessible reading experience.
- Use intuitive, minimalist icons for each rule category, with a focus on clarity and ease of understanding.
- Design a clean, intuitive layout that prioritizes easy navigation and quick access to information.
- Incorporate subtle animations for user interactions (e.g., highlighting corrections or showing progress) to provide visual feedback and encourage engagement.
